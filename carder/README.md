## Pour dupliquer le template (template-vehicule.html)
1. Copier `template-vehicule.html`
2. Renommer le fichier (ex: `bmw-m4-2024.html`)
3. Modifier uniquement l'objet `VEHICLE` dans le `<script>` en haut
